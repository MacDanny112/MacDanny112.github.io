Privacy Policy

Application: Hermes Agent — Personal Google Workspace Bridge
Operator and data controller: the owner of the connected Google account
Effective date: 29 September 2026

1. Scope

This policy covers the personal Google Workspace integration operated by the owner of the connected Google account (the “Application”). The Application runs locally on the operator's own computer and connects only to the operator's own Google account. There is exactly one user: the operator.

2. What Google user data is accessed

  • Gmail (gmail.readonly, gmail.modify, gmail.send): message metadata, subjects, senders, bodies and labels, to locate university and administrative correspondence and to prepare messages.
  • Google Calendar (calendar): event titles, times, locations and descriptions, to track classes, consultations and deadlines.
  • Google Drive (drive): file metadata and file contents, limited to the operator's own coursework and notes.
  • Google Sheets (spreadsheets) and Google Docs (documents): spreadsheet and document contents the operator is working on.
  • Contacts (contacts.readonly): names and email addresses, to resolve recipients when drafting messages.

3. How the data is used

Solely to assist the operator with their own study and administration — for example, summarising what is due this week, flagging missed submissions, and drafting documents and messages that the operator reviews before use. Data is not used for advertising, profiling, credit or lending decisions, or any purpose unrelated to assisting the operator.

4. Storage, retention and security

  • OAuth credentials and tokens are stored in a single local file on the operator's own computer. They are never uploaded or shared.
  • Google user data is processed in memory on that computer. Copies may exist transiently in local caches and logs, and are pruned automatically.
  • There is no server operated by the Application, no database of user data, and no cloud storage of Google user data.
  • Data is retained only as long as needed for the operator's study purposes, and can be deleted by deleting the local files or revoking access.

5. Sharing and disclosure

Google user data is not sold, rented, transferred or disclosed to any third party. It is not used to train machine-learning models, and it is not transferred to advertisers, data brokers or information resellers. The only external processing is the AI model request that generates the operator's own summaries; the operator controls and configures that provider.

6. Google API Services User Data Policy and Limited Use

The Application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Google user data is used only to provide the user-facing features described in section 3.
  • It is not transferred to others except as necessary to provide those features, to comply with applicable law, or as part of a merger or acquisition with notice.
  • It is not used for serving advertisements, including personalised or interest-based advertising.
  • It is not used for any purpose that a reasonable person would consider unrelated to the Application's stated purpose.
  • No humans read the operator's Google user data — the operator is the only person with access to it at all.

7. Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions, which immediately invalidates the Application's tokens. Local copies of Google user data can be deleted by removing the Application's local data directory. Because the operator is the sole user, revocation and deletion are complete and immediate from the operator's side.

8. Changes

Any change to this policy will be published on this page with an updated effective date.

9. Contact

Questions about this policy or about Google user data handled by the Application should be directed to the operator via the contact address registered on the Application's Google Cloud project.
